### 회의 안건
1. 프로젝트 주제 선정
2. 대상 회사 선정
3. 앱 기능 구상

### 회의 내용

#### 1. 대상 회사 선정
- **선정 회사**: BR IP Holder LLC. (베스킨라빈스)
- **선정 이유**:
  - 친근하고 대중적인 브랜드
  - 다양한 제품 라인업 (31가지 맛)
  - 이달의 맛 개념 활용 가능
  - 만 명 이상 사용자 만족 가능성 높음

#### 2. 앱 컨셉 결정
- **앱 이름**: 베스킨라빈스 도감 채우기 게임
- **핵심 컨셉**: 포켓몬 카드 수집 게임 스타일
- **목표**: 도감 완성을 통한 보상 제공

#### 3. 뽑기권 획득 방법 논의

**초기 아이디어**: 구매 인증
- 문제점: 구현 난이도 높음, 중학생이 따라하기 어려움
- QR코드, 영수증 OCR 등 복잡한 기술 필요

**최종 결정**: 일일 출석 + 퀴즈
- ✅ **일일 출석 체크**: 하루 1회 무조건 뽑기권 1장
- ✅ **일일 퀴즈**: 하루 1회 도전, 정답시 뽑기권 1장 (오답시 0장)
- ✅ **중복 교환**: 같은 카드 3장 = 뽑기권 1장
- **장점**: 
  - 구현이 간단함
  - 중학생도 쉽게 따라할 수 있음
  - 매일 접속 유도로 사용자 참여도 증가
  - 베스킨라빈스 브랜드 교육 효과

#### 4. 도감 시스템 구조

**일반 도감**
- 구성: 베스킨라빈스 정규 메뉴 30-40종
- 뽑기 확률: 5% (상대적으로 높음)
- 완성 보상: 확률형 제품 기프티콘

**리미티드 도감**
- 구성: 매월 이달의 맛 1종씩 (총 12종)
- 뽑기 확률: 1-2% (희귀함)
- 수집 기간: 해당 월에만 가능
- 완성 보상: 아이스크림 케이크 기프티콘 (확정)

**의의**: 
- 단기 목표(일반 도감) + 장기 목표(리미티드 도감)
- 수개월간 지속적인 플레이 유도

#### 5. 보상 시스템 설정

**일반 도감 완성 보상 (가격별 확률)**
| 제품명 | 가격 | 확률 |
|--------|------|------|
| 싱글 레귤러 | 3,900원 | 40% |
| 싱글 킹 | 4,700원 | 25% |
| 더블 주니어 | 5,100원 | 15% |
| 트리플 주니어 | 7,200원 | 8% |
| 더블 레귤러 | 7,300원 | 7% |
| 파인트 | 9,800원 | 3% |
| 쿼터 | 18,500원 | 1.5% |
| 패밀리 | 26,000원 | 0.4% |
| 하프갤론 | 31,500원 | 0.1% |

- 평균 기대값: 약 5,800원
- 저가 제품 80% / 중가 제품 18% / 고가 제품 2%
- 대부분 유저는 적당한 보상, 운 좋으면 대박!

**리미티드 도감 완성 보상**
- 아이스크림 케이크 기프티콘 100% 확정

### 의사 결정 사항
1. ✅ 구매 인증 방식 대신 출석+퀴즈 방식 채택
2. ✅ 도감을 일반/리미티드로 분리
3. ✅ 가격 기반 확률 보상 시스템 적용
4. ✅ 베스킨라빈스 브랜드 컬러(핑크, 브라운) 사용

### 향후 계획
- 퀴즈 문제 30개 이상 작성 (이예진 담당)
- 카드 데이터 수집 및 디자인 (강민우 담당)
- Cordova 환경 설정 (김산 담당)
