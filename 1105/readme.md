## 🎯 프로젝트 개요

베스킨라빈스의 아이스크림 맛을 수집하는 도감 게임 앱입니다.
매일 출석과 퀴즈를 통해 뽑기권을 얻고, 카드를 수집하여 도감을 완성하면 기프티콘을 받을 수 있습니다.

### 주요 기능
1. **일일 출석 체크** - 하루 1회 뽑기권 1장 획득
2. **일일 퀴즈** - 정답시 뽑기권 1장 추가 획득 (오답시 0장)
3. **뽑기 시스템** - 일반 카드와 리미티드 카드 수집
4. **도감 수집** - 일반 도감과 리미티드 도감 분리
5. **중복 교환** - 중복 카드 3장 = 뽑기권 1장
6. **완성 보상** 
   - 일반 도감 100% 완성 → 확률형 제품 기프티콘
   - 리미티드 도감 100% 완성 → 아이스크림 케이크 기프티콘

## 🚀 설치 및 실행 방법

### 1. 필수 프로그램 설치
- Node.js (v16 이상)
- Cordova CLI: `npm install -g cordova`

### 2. 프로젝트 생성
```bash
cordova create baskin-collection-game com.gencoder.baskin "베스킨라빈스 도감게임"
cd baskin-collection-game
```

### 3. 플랫폼 추가
```bash
cordova platform add android
# 또는
cordova platform add ios
```

### 4. 실행
```bash
# 브라우저에서 테스트
cordova serve

# Android 앱 빌드
cordova build android

# Android 실행
cordova run android
```
