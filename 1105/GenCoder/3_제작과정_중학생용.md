   ```
       ├── js/
       └── pages/
   ```

## 📂 3단계: 파일 구조 이해하기 (5분)

### 전체 구조
```
baskin-collection-game/
│
├── www/                    ← 웹 파일들
│   ├── index.html         ← 홈 화면
│   ├── css/
│   │   └── style.css      ← 디자인
│   ├── js/
│   │   ├── data.js        ← 카드 데이터
│   │   ├── storage.js     ← 저장 기능
│   │   └── app.js         ← 메인 로직
│   └── pages/
│       ├── attendance.html ← 출석체크
│       ├── quiz.html       ← 퀴즈
│       ├── gacha.html      ← 뽑기
│       ├── collection.html ← 도감
│       └── reward.html     ← 보상
│
├── README.md              ← 프로젝트 설명
└── config.xml            ← 앱 설정
```

### 각 파일의 역할

**HTML 파일**: 페이지 구조
- `index.html`: 게임 첫 화면
- `attendance.html`: 출석 체크하는 페이지
- `quiz.html`: 퀴즈 푸는 페이지
- `gacha.html`: 카드 뽑는 페이지
- `collection.html`: 도감 보는 페이지
- `reward.html`: 보상 받는 페이지

**CSS 파일**: 디자인
- `style.css`: 색깔, 크기, 애니메이션

**JS 파일**: 기능
- `data.js`: 카드 정보 저장
- `storage.js`: 데이터 저장/불러오기
- `app.js`: 게임 동작

## ✏️ 4단계: 코드 수정해보기 (10분)

### 수정 1: 제목 바꾸기

1. **VS Code로 index.html 열기**
2. **16번째 줄 찾기**
   ```html
   <h1>베스킨라빈스 도감</h1>
   ```
3. **원하는 제목으로 변경**
   ```html
   <h1>나만의 아이스크림 도감</h1>
   ```
4. **저장 (Ctrl + S)**
5. **브라우저 새로고침 (F5)**

### 수정 2: 팀 이름 바꾸기

1. **index.html에서 143번째 줄 찾기**
   ```html
   <div class="team-name">Team GenCoder</div>
   ```
2. **변경하기**
   ```html
   <div class="team-name">나의 팀 이름</div>
   ```
3. **저장하고 새로고침**

### 수정 3: 색깔 바꾸기

1. **css/style.css 열기**
2. **9번째 줄부터 색깔 정의**
   ```css
   --pink-main: #FF6B9D;    ← 메인 핑크색
   --pink-light: #FFB3D1;   ← 연한 핑크색
   --brown-main: #8B4513;   ← 브라운색
   ```
3. **원하는 색으로 변경**
   ```css
   --pink-main: #FF1493;    ← 진한 핑크로!
   ```
4. **저장하고 확인**

## 📱 6단계: 모바일 앱으로 만들기 (고급)

### 준비물
- Node.js 설치
- Android Studio (안드로이드폰 사용시)
- Xcode (아이폰 사용시, Mac 필요)

### Cordova 설치

1. **명령 프롬프트 열기**
   ```bash
   npm install -g cordova
   ```

2. **플랫폼 추가**
   ```bash
   cd baskin-collection-game
   cordova platform add android
   ```

3. **앱 빌드**
   ```bash
   cordova build android
   ```

4. **폰에 설치**
   ```bash
   cordova run android
   ```

## 🌐 7단계: 인터넷에 올리기 (10분)

### GitHub Pages로 호스팅

1. **GitHub 가입**
   - https://github.com
   - 무료로 가입

2. **새 Repository 만들기**
   - "New Repository" 클릭
   - 이름: `my-collection-game`
   - Public 선택
   - "Create" 클릭

3. **파일 업로드**
   - "Add file" → "Upload files"
   - `www` 폴더 전체를 드래그
   - "Commit changes" 클릭

4. **GitHub Pages 설정**
   - Settings → Pages
   - Source: "main" branch
   - Folder: "/ (root)"
   - Save

5. **링크 확인**
   ```
   https://사용자이름.github.io/my-collection-game/
   ```
   - 5분 후 접속 가능!
   - 친구들에게 공유하기

## 🐛 8단계: 문제 해결 (FAQ)

### Q1: 페이지가 안 열려요!
**A**: Chrome 브라우저로 열었는지 확인하세요.
```
index.html 우클릭 → 연결 프로그램 → Chrome
```

### Q2: 출석체크가 안 돼요!
**A**: 브라우저 쿠키 설정을 확인하세요.
```
Chrome 설정 → 개인정보 → 쿠키 허용
```

### Q3: 데이터가 날아갔어요!
**A**: localStorage가 초기화되었습니다.
```
F12 → Console → localStorage.clear() 입력하지 않기
```

### Q4: 폰에서 안 돼요!
**A**: 파일을 GitHub에 올리고 링크로 접속하세요.

### Q5: 색깔이 안 바뀌어요!
**A**: 브라우저 캐시를 지우세요.
```
Ctrl + Shift + Delete → 캐시 삭제
```
