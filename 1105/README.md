## 🎮 게임 소개

베스킨라빈스의 **인기 메뉴 30종**과 **이달의 맛 12종**을 수집하는 모바일 도감 게임입니다.

- 매일 출석체크와 퀴즈로 뽑기권 획득
- 확률형 카드 뽑기 시스템  
- 독창적인 포인트 마일스톤 보상
- 프로급 애니메이션 10종
- 실제 베스킨라빈스 기프티콘 보상

## ✨ 주요 기능

### 📅 출석체크 & 퀴즈
- 매일 1회 출석 → 뽑기권 1장
- 매일 1회 퀴즈 정답 → 뽑기권 1장
- 최대 하루 2장 획득 가능

### 🎰 뽑기 시스템
- **기본맛 카드**: 95% 확률
- **이달의 맛**: 5% 확률 (매월 변경)
- 중복 카드 3장 → 뽑기권 1장 자동 교환

### 💎 포인트 마일스톤 (독창적!)
- 이달의 맛 1장 = **100 포인트**
- 300pt → 싱글 레귤러 (3,900원)
- 600pt → 더블 레귤러 (7,300원)
- 900pt → 파인트 (9,800원)
- 1200pt → 아이스크림 케이크 🎂

### 🎁 기프티콘 보상
- 기본맛 도감 완성 → 확률형 뽑기
- 최저 3,900원 ~ 최고 **40,000원!** (0.01%)
- 💎 전설 등급 도전!

### ✨ 프로급 애니메이션
- 카드 뒤집기 효과
- 리미티드 황금빛 글로우
- 포인트 상승 애니메이션
- NEW 뱃지 반짝임
- 부드러운 전환 효과

## 🚀 설치 및 실행

### 웹 브라우저에서 실행
```bash
# 1. 저장소 클론
git clone https://github.com/your-username/baskin-collection-game.git

# 2. 프로젝트 폴더로 이동
cd baskin-collection-game

# 3. www/index.html 실행
# 브라우저에서 파일 열기
```

### 로컬 서버로 실행
```bash
# Python 3
cd www
python -m http.server 8000

# 브라우저에서 http://localhost:8000 접속
```

### Cordova로 모바일 앱 빌드
```bash
# Cordova 설치
npm install -g cordova

# Android 플랫폼 추가
cordova platform add android

# 빌드
cordova build android

# 실행
cordova run android
```

## 🎮 게임 플레이 가이드

### 시작하기
1. 홈 화면에서 **출석체크** 클릭 → 뽑기권 1장
2. **퀴즈** 풀기 → 정답시 뽑기권 1장 추가
3. **뽑기** 메뉴로 이동

### 카드 수집하기
1. 뽑기권 사용해서 카드 획득
2. 기본맛(95%) 또는 이달의 맛(5%) 랜덤
3. 새 카드 획득시 도감에 자동 등록

### 포인트 쌓기
1. 이달의 맛 카드 획득 → +100pt
2. 포인트 마일스톤 달성 → 기프티콘 획득
3. 12개월 모두 수집 → 1,200pt → 아이스크림 케이크!

### 도감 완성하기
1. 기본맛 30종 완성 → 확률형 기프티콘
2. 0.01% 확률로 40,000원 전설 등급 도전!
