# 김산 포트폴리오 (Kim San's Portfolio)

**모바일 앱 개발 및 음악 기술 전문가**

## 1. 소개

안녕하세요! 모바일 앱 개발과 음악 기술의 융합에 열정을 가진 개발자, 김산입니다. 이 포트폴리오는 제가 동의과학대학교 컴퓨터 소프트웨어과에서 쌓아온 기술 역량, 실무 경험, 그리고 개인적인 관심사를 체계적으로 보여주기 위해 제작되었습니다.

기술을 통해 창의적인 솔루션을 만들고, 사용자에게 긍정적인 경험을 제공하는 것을 목표로 합니다.

## 2. 주요 섹션

* **소개:** 저의 전문적인 목표, 기술 스택, 그리고 자기소개를 담고 있습니다.
* **인적:** 기본적인 인적 사항 및 학력 정보를 포함합니다.
* **경력:** 버스킹 공연, 일본 유학 및 호텔리어 경력을 통해 얻은 소통, 문제 해결, 그리고 고객 서비스 역량을 보여줍니다.
* **학술:** 학업 과정에서 진행한 주요 프로젝트(음악 편집 앱 개발)에 대한 상세 설명과 성과를 기록했습니다.

## 3. 기술 스택

이 포트폴리오 페이지는 웹 개발의 기본 기술을 활용하여 제작되었으며, 사용자 친화적인 경험을 제공합니다.

* **HTML5:** 웹 페이지의 구조와 콘텐츠를 담당합니다.
* **CSS3:** 반응형 디자인과 현대적인 스타일링을 적용하여 모든 기기에서 최적화된 화면을 제공합니다.
* **Java, Python, Android SDK:** 주요 프로젝트에서 활용된 핵심 기술입니다.

## 4. 프로젝트 실행 방법
