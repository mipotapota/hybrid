주요 프로젝트

Android Studio 기반 음악 편집 앱 개발

프로젝트 개요: 사용자가 손쉽게 음악을 녹음하고 편집하여 개인 버스킹 공연에 활용할 수 있도록 돕는 모바일 앱을 개발했습니다. 이 프로젝트는 기획부터 구현, 데이터 관리까지 전 과정을 직접 수행했습니다.

주요 기술: Android SDK, Java, XML, SQLite

담당 역할:

  • UI/UX 설계: 직관적인 사용자 인터페이스를 디자인하여 누구나 쉽게 앱을 사용할 수 있도록 했습니다.
  • 기능 구현: 오디오 녹음 및 재생 기능을 구현하고, 음정/박자 편집 기능을 추가했습니다.
  • 데이터베이스 관리: SQLite를 활용하여 사용자의 음원 파일을 효율적으로 저장하고 관리하는 데이터베이스 시스템을 구축했습니다.
