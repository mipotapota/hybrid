# 김산 개인 포트폴리오

**모바일 앱 개발 및 음악 기술 전문가**

## 프로젝트 개요

이 프로젝트는 동의과학대학교 컴퓨터소프트웨어과에 재학 중인 김산의 개인 포트폴리오 웹사이트와 학과 소개 앱으로 구성되어 있습니다. 기술적 역량과 실무 경험을 효과적으로 보여주는 것을 목표로, 현대적이고 전문적인 디자인을 적용했습니다.

### 1. 개인 포트폴리오 웹사이트

저의 성장 과정과 핵심 역량을 보여주는 반응형 웹 포트폴리오입니다.
* **주요 섹션:**
    * **소개:** 자기소개와 기술 스택을 소개합니다.
    * **인적:** 학력 및 인적 사항을 정리합니다.
    * **경력:** 버스킹 공연과 일본 유학/호텔리어 경험을 통해 얻은 소프트 스킬을 강조합니다.
    * **학술:** 'Lumaire' 앱 개발 프로젝트를 상세히 설명합니다.
    * **블로그 & 깃허브:** 기술 블로그와 깃허브 링크를 제공하여 지속적인 학습과정을 공유합니다.

### 2. 동의과학대학교 컴퓨터소프트웨어과 소개 앱

학과 정보를 모바일 환경에 최적화하여 제공하는 앱 형태의 HTML 페이지입니다.
* **주요 컨텐츠:**
    * **학과 안내:** 학과 소개, 관련 자격증, 4년제 대학 연계편입 정보를 담고 있습니다.
    * **학과 영상:** 학과 관련 유튜브 영상들을 모아서 보여줍니다.
    * **취업 및 진로:** 졸업 후 진출할 수 있는 다양한 IT 분야와 연계 편입 정보를 안내합니다.
    * **학과 갤러리:** 학과 관련 사진들을 모아 갤러리 형태로 제공합니다.

## 핵심 기술 스택

* **웹 개발:** HTML5, CSS3 (반응형 웹 디자인 적용)
* **모바일 웹:** jQuery Mobile
* **프로그래밍 언어:** Java, Python, C++
* **프레임워크/플랫폼:** Android SDK, TensorFlow, Flask
* **개발 도구:** Git, GitHub, Android Studio, PyCharm

## 실행 방법

1.  이 저장소를 클론(clone)합니다.
    ```bash
    git clone [저장소 URL]
    ```
2.  개인 포트폴리오는 `mintro.html` 파일을, 학과 소개 앱은 `dit_app.html` 파일을 웹 브라우저에서 열어 실행합니다.
