# 동의과학대학교 컴퓨터소프트웨어과 소개 웹페이지

이 프로젝트는 동의과학대학교 컴퓨터소프트웨어과를 소개하는 반응형 웹페이지입니다. 학과 정보, 교육 과정, 진로 및 취업 분야, 그리고 갤러리 등의 주요 콘텐츠를 포함하고 있습니다.

## 주요 특징

-   **현대적인 디자인**: HTML5, CSS3를 사용하여 깔끔하고 사용자 친화적인 디자인을 구현했습니다.
-   **반응형 웹**: PC, 태블릿, 모바일 등 다양한 기기에서 최적의 화면을 제공합니다.
-   **간편한 탐색**: 페이지 내 스크롤 방식으로 사용자가 원하는 정보를 빠르게 찾을 수 있습니다.
-   **깔끔한 콘텐츠 구성**: `collapsible` 메뉴를 사용하여 많은 양의 정보를 효율적으로 정리했습니다.
-   **외부 라이브러리 최소화**: 불필요한 jQuery Mobile 라이브러리를 제거하여 페이지 로딩 속도를 향상시켰습니다.

## 사용 기술

-   **HTML5**: 웹페이지의 구조를 만듭니다.
-   **CSS3**: 디자인과 레이아웃을 담당합니다.
-   **JavaScript (ES6+)**: 페이지 내 동적인 기능을 구현합니다. (예: 스무스 스크롤, 메뉴 확장/축소)
