# ✈️ ANA 전일본공수 회사 소개 앱

![ANA Logo](https://img.shields.io/badge/ANA-全日本空輸-003E7E?style=for-the-badge)
![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white)
![jQuery Mobile](https://img.shields.io/badge/jQuery_Mobile-0769AD?style=for-the-badge&logo=jquery&logoColor=white)
![Bootstrap](https://img.shields.io/badge/Bootstrap_5-7952B3?style=for-the-badge&logo=bootstrap&logoColor=white)

일본 최대 항공사 ANA(전일본공수)를 소개하는 모바일 웹 애플리케이션입니다.

## 📋 프로젝트 개요

이 프로젝트는 동의과학대학교 웹 프로그래밍 과제로 제작된 ANA 항공사 소개 및 채용 정보 제공 앱입니다.

### 🎯 주요 목적
- ANA 항공사에 대한 종합적인 정보 제공
- 채용 정보 및 복리후생 안내
- 항공기 갤러리 및 서비스 소개
- 모바일 친화적인 사용자 경험 제공

## ✨ 주요 기능

### 🏢 회사 소개
- **회사 연혁**: 1952년 창립부터 현재까지의 역사
- **기업 미션**: "Inspiration of Japan" - 일본의 가치 전파
- **글로벌 네트워크**: 48개국 취항, 260대 항공기 보유
- **Accordion UI**: Bootstrap 5 활용한 인터랙티브 정보 제공

### 💼 채용 정보
- **객실 승무원**: 일본어 JLPT N1, 영어 TOEIC 600점 이상
- **공항 지상직**: 체크인, 탑승 수속, 고객 안내
- **라운지 서비스**: VIP 고객 대상 프리미엄 서비스
- **복리후생**: 항공권 할인, 기숙사, 4대 보험, 교육 프로그램

### 🎬 소셜미디어
- YouTube 공식 채널 링크
- Instagram 공식 계정 연결
- Facebook 페이지 바로가기

### ⭐ 서비스 안내
- **일등석**: 180도 풀플랫 시트, 프리미엄 기내식
- **비즈니스 클래스**: 스타거드 시트, 일본식 정찬
- **프리미엄 이코노미**: 38인치 좌석 간격
- **이코노미 클래스**: 31-34인치 표준 좌석

### 🖼️ 항공기 갤러리
- Boeing 777, 787, 767, 737
- Airbus A380, A320, A321
- 특별 도장 항공기 (Star Wars, Pokemon, Hello Kitty)
- SVG 그래픽으로 제작된 항공기 일러스트

## 🛠️ 기술 스택

### Frontend
- **HTML5**: 시맨틱 마크업
- **CSS3**: 그라데이션, 애니메이션, 반응형 디자인
- **JavaScript**: jQuery 기반 인터랙션

### Frameworks & Libraries
- **jQuery Mobile 1.4.5**: 모바일 UI 프레임워크
- **Bootstrap 5.3.0**: 반응형 레이아웃 및 컴포넌트
- **Font Awesome 6.4.0**: 아이콘 라이브러리

### Design
- **SVG Graphics**: 항공기 및 로고 일러스트
- **Custom Theme**: ANA 브랜드 컬러 (#003E7E, #0070C0, #001F3F)
- **Gradient Effects**: 현대적인 그라데이션 디자인

## 🚀 시작하기

### 설치 방법

1. **레포지토리 클론**
```bash
git clone https://github.com/your-username/ana-company-app.git
cd ana-company-app
```

2. **브라우저에서 실행**
```bash
# 단순히 HTML 파일을 브라우저에서 열기
open dokdo-intro.html
# 또는
start dokdo-intro.html
```

### 요구사항
- 모던 웹 브라우저 (Chrome, Firefox, Safari, Edge)
- 인터넷 연결 (CDN 리소스 로딩용)
